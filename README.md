# Mochi Quest

**[作品選択](https://mochi-quest.mochi-quest.workers.dev/)**

- [Mochi Quest 2　四季十七景巡り](https://mochi-quest.mochi-quest.workers.dev/two/) は、鳥獣戯画の里を歩く三人称の3Dオープンワールド。川や海を泳ぎ、建物の戸口をくぐり、海底の竜宮城と雲上の伏見稲荷を含む十七の名所で御朱印を集められます。
- [Mochi Quest 1　絵巻道中](https://mochi-quest.mochi-quest.workers.dev/one/) は、墨絵の世界を横に旅する第一作です。

## 十七景もち寄り帖

桜川の渡しで、餅屋のおはなが舟を止めます。十二個のせたはずの花筏餅が、ひとつ足りません。頭の上に **「…」** が浮かぶ相手に近づいて **E**。タッチでは吹き出しか「話しかける」を押します。移動画面に顔と名前が出たら、**E** で続きを読み、数字キーか画面の選択肢で配達人のお餅の言葉や行動を選びます。離れるか **Esc** で会話を終えられます。三条通知の配達は **Z** です。

おはなが餅を持ち上げて裏返すところも、職人が蒸し箱に桟を戻すところも、その場で見届けられます。品物を預かったら、届け先で相手に声をかけて手渡します。**J** の帳面では預かり物と手掛かりを確認し、次に訪ねる相手の場所に道しるべを付けられます。「場面の回想」からは見た場面を再生できます。

七つの謎、京の白洲での二度の裁判、二つの秘境への招待が、既存の旅に加わります。途中で帳面を閉じて湯巡りや配達に戻れます。設計資料には結末までの内容を含みます。[謎解きと絵巻の実装計画](docs/mochiyori-design.md) ／ [実画面と造形の検版記録](docs/mochiyori-review/README.md)

## Mochi Quest 2 の操作

小地図は「小・中・大」と、伸ばした餅の形をした縦長の「餅」から選べます。「＋・−」で縮尺を調節し、地図をドラッグすると旅の画面のまま周囲を見渡せます。「現在地へ」を押すとお餅を追う表示に戻ります。M キーか小地図を一度押して地図帳を開くと、ホイールやピンチで拡大縮小できます。地図上で印を打つほか、温泉、自転車ポート、茶屋などを一覧から選んで道しるべにできます。朱の襟巻きのお餅がカメラから見た八方向を指し、残りの距離を知らせます。地図の設定と道しるべは次の旅にも引き継がれます。

矢印キーか WASD でカメラを基準に前後左右へ移動します。ドラッグまたは Q・R で視点を回転し、Space でジャンプし、空中で押すたびに体が伸びます。Z で三条通知、E で調べる・乗降、0〜5 で餅モードの切り替えができます。スマートフォンでは左スティックで歩き、画面をなぞって周囲を見回します。

どの餅モードでも、移動するとカメラがゆっくり背後へ回り、行く先を見渡せます。歩くときも、団子で転がるときも、泳いだり空を飛んだりするときも、ドラッグや Q・R で自由に見回せます。右上の「設定」にある「餅の進行方向にカメラを合わせる」は初期設定でオンです。オン・オフの選択は次の旅にも引き継がれます。

草餅は木・岩・建物・動物をすり抜け、橋の下を泳げます。自転車やカメに乗ったままでも、2 または「草餅」で乗り物ごとすり抜け、0 または「白餅」で元に戻れます。徒歩の草餅で道具や温泉を使うには、そばで E を押します。羽二重餅はジャンプの連打か長押しで足元の地面から180mまで上昇できます。山頂から飛び立っても同じ高さだけ上がれます。飛びながら前に進むと加速します。きなこ餅の三条通知は周囲八方向、ラーメンで満腹になると二十四方向へ同時発射します。電動自転車は陸の十四景のポートで借りたり返したりできます。

桜川・松浜・雪浜に繫いだ四隻の小舟、桜川を往復する三隻の高瀬舟、沖を行く二隻の帆掛け舟には、舟べりで E を押すと乗れます。タッチでは舟の名が出たボタンを押します。動く舟に腰掛けて景色を眺め、もう一度押すと岸や水面に降りられます。

花の京の南口では、石畳から幅広の石段を上がると、石積みの基壇に建つ羅生門をくぐれます。東脇の木階段の先には老婆餅が暮らし、大路には平安末期の装いをした旅人や商人が行き交います。お茶とみたらし団子は店先で E。夕暮れには辻で番をしていた衛士が松明を運び、街角の篝火を順に灯します。京を囲むなだらかな山並みにも火が入り、北山に「大」、東山に「福」の文字が浮かびます。朱雀大路と東西の大通りが交わる辻から、向きを変えて二つの山を見渡せます。西の桃源郷へは、竹隠れの社から尾根の間を縫う谷道をたどります。月門のまわりには紅や薄桃の花が咲き、山腹の桃林を幾重もの霞が横切ります。里に着くと「花桃の瓢湯」でひと休みできます。南の東大寺には大餅仏が鎮座します。京の南にある伏見稲荷の千本鳥居は雲上の奥社へ続き、天気雨の中を狐の花嫁が通ります。伏見稲荷では麓から山頂まで、晴れた空の下を局地的な強い通り雨が横切ります。雨脚が強まると雨音がふくらみ、ときおり遠くで雷が鳴ります。桃の花の下では兎と蛙が相撲を取り、東大寺の参道では鹿にお辞儀を返す兎に会えます。竜宮城では、太鼓を打つ海亀、扇を持つ鯛、書をしたためる蛸が各8匹おり、それぞれに三条通知を届けられます。街道を往復する牛車と海を巡る餅商人が旅の目印です。竜宮の生き物の造形と墨の筆致は、東京国立博物館の模本を参考にしています。[ColBase「鳥獣戯画（模本）」](https://colbase.nich.go.jp/collection_items/tnm/A-1530?locale=ja)

京の南東、石の道標から参道を登ると清水寺です。西に張り出す木の舞台からは、店先の提灯や行燈、灯籠、五重塔の各階に灯った障子を見渡せます。町家の室内と評定の間には燭台が立ちます。境内では僧侶餅が舞台を掃き、経を読み、数珠を手に巡堂します。鐘楼では鐘守が48秒ごとに梵鐘を撞きます。柱の間から梵鐘を向いて Z（タッチでは三条通知）を押すと、紙札でも鳴らせます。本堂の懸造と境内の構成は清水寺の公式案内を参考にしました。[音羽山 清水寺「境内案内」](https://www.kiyomizudera.or.jp/map.php)

花の京では、東西の大通りを西へ進み、門前から北に入ると、広い白洲と、一続きの障壁画を望む評定の間を備えた大きな裁判所「京の評定所」があります。大餅仏の傍らには象が2頭、野山には獏が10頭、街道や牧には牛が10頭います。鷹10羽は木の枝に降りて羽を休め、鶏40羽は都の路地に、魚人7人は海底の竜宮城に暮らしています。

外周の五景を隔てる距離が従来の2倍になりました。十七景それぞれに一つずつ主湯があり、街道や山あいには小さな脇湯が十一か所あります。地図の朱色の「♨」が主湯、青墨の「湯」が脇湯です。名所を選ぶと湯や休憩所の名前、方角、距離が分かります。花の京の硯湯は、朱雀大路と東西の大通りが交わる辻の南西、蛙と兎が団子を焼く屏風の前にあります。唐破風の門をくぐると、築地塀の内側に黒い硯の湯船があり、隣の染め物屋跡には四席の洗い場があります。洗い場で E（タッチでは画面の操作ボタン）を押すと、手桶で肩に掛け湯をします。硯の浅い縁では腰掛石に座り、中央の深みでは仰向けになって湯面に沿って伸びます。蔵町では三つの釉薬の甕から一つを選び、棚田では畦を越えて上下の湯を巡れます。松浜の網元汐湯では、浜から汲み上げた海水を塩釜で熱し、木樋で真水と合わせます。釜出しの肩湯と網代のぬる汐湯を選べて、湯屋には真水のすすぎ桶があります。堺の陶室蒸し湯では、焚口の脇を通って陶のアーチをくぐり、蒸気の通る腰掛けでひと休みできます。湯上がりには HP と MP が全回復します。評定所の障壁画と動物の身ぶりは、東京国立博物館所蔵の山崎董詮による模本を造形の参考にしました。[ColBase「鳥獣戯画（模本）」](https://colbase.nich.go.jp/collection_items/tnm/A-1530?locale=ja)

錦秋の楓峡では、朱橋から西を向くと、岩間の湧き水が楓清水の滝となって足もとの川に注ぎます。地図の「滝」をたどると、楓橋の東に楓渓の滝、竹隠れの社から桜川へ下る沢に白糸の滝、桃源郷の南斜面に桃霞の滝があります。

街道沿い九軒の団子茶屋は地図の「茶」が目印です。縁台で E（タッチでは「団子とお茶をいただく」）を押すと、桜団子と桜葉茶、よもぎ団子とほうじ茶など、土地の団子とお茶で体力とモッチポイントが全回復します。

村と港を結ぶ街道を、籠売り、反物商、薬売りなど74人の商人餅と4台の牛車が往復します。京と堺を結ぶ道や、京から湯けむり峠、蔵町の市を経て東大寺の大餅仏に至る道では、行きと帰りの商人たちがすれ違います。桜川は東西の海へ通じ、商人餅の荷舟が三つの橋の下を往復します。山に五軒の炭焼き小屋、浜に四軒と川岸に二軒の漁師小屋があります。地図では「炭」と「漁」が目印です。どの小屋でも木段を上って五右衛門風呂に入り、E（タッチでは入浴ボタン）で体力とモッチポイントを全回復できます。

花の京から北東へ峠を越えると、冬の海に面した雪灯りの街に着きます。雪灯籠の並ぶ参道から五重塔に登ると、北には白波の立つ岩礁と帆を上げた漁舟が見えます。かつて街があった内陸のくぼ地には湖が広がり、柳の下では蛙が石を投げ、兎が水切りを見物しています。

京から北山の裾を回って北の海に出ると敦賀の津に着きます。京の南西の港町は堺です。桟橋から大船の甲板に渡り、甲板中央の階段を下って船倉を訪ねられます。各港で48秒停まる定期船に乗ると、岩礁を望む西の外洋を経て約4分半で対岸の港に着きます。外洋の廻船は敦賀と堺の両方に20秒ずつ寄港します。敦賀から東へ出る時計回りと、西へ出る反時計回りがあり、どちらも約22分で一周します。

泳いでいるときも ↓ または S で手前へ移動します。Space と ↓（または S）を一緒に長押しすると潜水し、両方を離すと深さを保ちます。水中で Space を長押しすると浮上し、水面で Space を押すとジャンプします。タッチでは「潜る」で潜水、ジャンプボタンで浮上・水面ジャンプができます。

竜宮沖では、真珠灯籠をたどって海底の楼門をくぐると御朱印所です。その奥の御殿には、海底から泳ぎ込める水門があります。内海の水面に出て、奥の段から板間に上がってください。紫の装束に冠を着けた魚人たちが行き交う御殿を三階まで上がると、巻貝を湯船にした主湯「栄螺の壺湯」に入れます。

地図の「この地の動物に届ける」で、選んだ土地の未配達の一匹を探せます。配達帳で動物を選ぶと、未配達の一匹までの方角と距離が分かります。全861匹に届けると、四方紅の上に裏白を敷き、背中に餅花を負った鏡餅に変身できます。ジャンプの連打か長押しで、両手に持った紅白の紙垂を羽ばたかせて空を飛びます。地図に印を置いた場所へ瞬間移動もできます。以前の配達点と現役の動物への配達記録、一度開いた鏡餅も引き継ぎます。

茶屋でお茶を運ぶ蛙や、酒蔵で柄杓を動かす職人にも通知を届けられます。暖簾をくぐると、屋内の仕事を間近で眺められます。

錦秋の楓峡には紅葉・黄葉する木が400本あります。桜川では鹿の背にまたがる兎に出会えます。虎と獅子は人家や街道から離れた野山に暮らします。桜川で新しい旅を始めたら、蔵町の屋根の上を見上げてみてください。枝角と長いひげを持つ龍が横切り、山や海の上へ泳いでいきます。龍と麒麟は一周ごとに道筋を変え、十七景すべての空を渡ります。配達帳で選ぶと、地上からでも現在の方角、距離、高低差を確かめられます。丹頂はさまざまな高さを飛びます。空を渡る小鳥の群れは配達の対象外です。猿の顔や獅子の身ぶり、動物同士の遊びは高山寺の絵巻を参考にしています。[高山寺「鳥獣人物戯画」](https://kosanji.com/chojujinbutsugiga/)

M で地図、C でお顔カメラ、Esc で一時停止。お顔カメラでは表情を選び、写真を保存できます。最初の操作で音が入り、十七景の境を越えるとBGMがゆっくり切り替わります。竜宮沖は海面・潜水中・御殿で、船と自転車は乗降で曲が替わります。右上の「設定」で効果音・環境音・BGMを個別に調整でき、「曲とエリアの一覧」から旅の選曲を確認できます。音量はこのブラウザに保存されます。スピーカーボタンで全体を消音できます。旅の記録は各作品ごとに同じブラウザに自動保存されます。「設定」の「ゲームをリセット」で確認すると、音量設定を引き継いで桜川の渡しからやり直せます。

GitHub Pages で遊んでいた場合は、同じブラウザで[旧版の手引き](https://ishida-konbu.github.io/mochi-quest/two/#guide)を開き、「Cloudflare版に旅の記録を引き継ぐ」を選んでください。Cloudflare 版に旅の記録がある場合は、二つの記録を見比べてから選択できます。

## 開発と公開

リポジトリの直下で `python3 -m http.server 8080` を実行し、[作品選択ページ](http://localhost:8080/)を開きます。Node.js 22 で `npm test` を実行すると両作品のゲームロジックを検証できます。外部パッケージのインストールは不要です。

本番は Cloudflare Workers Static Assets の Worker `mochi-quest` です。Cloudflare Workers Builds が GitHub の `ishida-konbu/mochi-quest` の `main` への push を受け取り、リポジトリ直下で `npm run build` と `npx wrangler deploy` を順に実行します。ビルドでは先に全テストを実行し、失敗した場合は公開を止めます。

リポジトリのルートで `npm ci` の後、`npm run dev` で配信構成をローカル確認できます。`npm run deploy` は配信用のファイルを `dist/` に集めて公開します。第二作は WebGL 2 を使用します。Three.js r180 を [MIT ライセンス](two/vendor/THREE-LICENSE.txt) の下で同梱しています。旅の環境音・効果音の出典とライセンス、掛け声の音声モデルは [音声クレジット](audio/CREDITS.txt) に記載しています。

第二作の選曲は [20曲の対応表](two/journey-music.js) にあります。船に乗ると「Water Mirror」が流れます。大型船の甲板では海風が聞こえ、餅が歩いたときに足音が鳴ります。初日の出の浦では「Ittekimasu」に浜の波と餅つきの音が重なります。現在地の曲を流しながら、進行方向の境界や自転車ポート、水門の近くでは次の1曲の読み込みを準備します。次の音源が再生できると曲が重なって替わり、同じ土地に長くとどまると曲の終わりに次の周回のイントロが重なります。

ゲーム用の音源を取り込むには、公式ファイル名のMP3・WAVを `BGM/` に置き、FFmpegのある環境で `node tools/import-journey-music.mjs BGM` を実行します。`audio/music/` に音量を揃えたMP3と、各曲のバイト数・SHA-256を記録した `available.json` ができます。新規音源を含むリリースは、その端末で `npm run deploy` を実行してからコードと一覧を `main` に反映します。クリーンなチェックアウトからの継続ビルドでは、ゲーム配信元の同じ音源を取得し、サイズとハッシュを検証して梱包します。各曲は必要なバイト範囲を取得でき、内容に応じたURLでブラウザーにキャッシュされます。

第二作の遠景には描き下ろしの山水画を使用しています。お餅や水辺に映る朝の環境光には Greg Zaal の HDRI を軽量化して使用しました。[Spruit Sunrise](https://polyhaven.com/a/spruit_sunrise) ／ [CC0](https://polyhaven.com/license)

桜川の浅瀬と海岸には Kless Gyzen の苔岩6種を配置しています。配信用モデルは元の色と凹凸のテクスチャを活かして約4千ポリゴンに軽量化しました。川床の礫にも同じ6種を使い、真上から写し取った石の陰影を大きさの異なる三層に重ねています。[Rock Moss Set 01](https://polyhaven.com/a/rock_moss_set_01) ／ [CC0](https://polyhaven.com/license)

足元の草花は20系統、それぞれに5通りの草姿を描き分けています。木陰には笹や薇、川辺には沢瀉、浜には浜昼顔が群生します。原画の生成コードと配信用アトラスを CC0 で公開しています。[植物画のソース](tools/paint-meadow.mjs) ／ [アトラス](two/assets/world/meadow-herbs.webp) ／ [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
