# 創作餅・レシピ・品質計算

有限の材料定義と技法を掛け合わせ、個別の専用モデルや手書きレシピを作らず多様な餅を生み出す。伝統餅と創作餅を明確に区別する。

## レシピの7軸

**CRAFT-01 [REQ]** 素材の組み合わせから独自の餅を制作でき、名前・見た目・用途を持つ。ほぼ無限のバリエーションを感じられる設計。事前に用意したレシピを選ぶだけにしない。

| 軸 | 初期案 | データ上の扱い |
|---|---|---|
| 生地 | 白もち米、玄もち米、あわ入り、葛入り | 生地IDと基礎数量。複数原料の配合は後拡張 |
| 主食材 | 小豆、栗、桃、よもぎなど | 0〜1種、混ぜ込み/餡/上掛けの配置 |
| 副食材 | 柚子、胡麻、桜、昆布など | 0〜2種、主食材と重複時は正規化 |
| 調理法 | 蒸す・搗く（基本工程）、焼く、揚げる、冷やす、乾燥 | 生地の安全な基本加工＋仕上げ。生米を生のまま食品扱いしない |
| 味付け | 無調味、塩、砂糖、醤油、味噌、蜜 | 0〜1種、必要量と強度 |
| 造形 | 丸、角、三角、包み、重ね、ねじり、花、ちぎり | 形状と構造。包み/餡は互換ルール |
| 技法 | 半搗き、薄伸ばし、笹包み、凍み、湯蒸し、職人技 | 技法IDと前提・設備・習得済み。選択0〜2、衝突判定 |

技法に地域の文化を持たせる（単に「京風」を選ぶだけではない）。例えば雪灯りの街で学んだ凍み技法と堺で学んだ鉄板焼きを、妥当な工程として順に用いる。地域は発祥/習得先と文化タグにより表現し、所有者の名前やレシピ名とは別管理。伝統餅の技法を真似ても元の土地の公式伝統餅にはならない。

### 組み合わせの規模

仮に生地4、主食材24、単一副食材9（なし含む）、仕上げ6、調味6、形8、技法5なら直積は1,244,160通り。これは独立を仮定した例で、実際は工程制約・重複正規化・解放条件で減り、配合比や複数副食材で増える。組み合わせを先に全列挙しない。ゲーム内で生成・保存するのは発明したレシピと必要な生産ロットのみ。

## データ契約（初期案）

**CRAFT-02 [DESIGN]** `Recipe` と `Batch` を分離する。定義とプレイヤーが付ける名前、製造した個数を混ぜない。下は概念例、最終スキーマは [技術](architecture.md) と同期する。

```json
{
  "recipeId": "recipe_01",
  "schemaVersion": 1,
  "base": {"id":"rice_white", "amount":100},
  "fillings": [
    {"id":"chestnut", "amount":20, "role":"main", "placement":"inside"},
    {"id":"yuzu", "amount":5, "role":"accent", "placement":"mixed"}
  ],
  "finish": "grill",
  "seasoning": {"id":"honey", "amount":5},
  "shape":"round",
  "techniques":["half_pound"],
  "originRegionId":"autumn",
  "name":"楓霞餅",
  "description":"栗のほくほくした食感に柚子の香りを重ねた焼き餅。",
  "createdMinute":480,
  "rulesVersion":1
}
```

`Batch {batchId, recipeId, recipeRevision, craftedMinute, quantity, attributesSnapshot, appearanceKey, costBasis, freshnessPolicy}`。初期は一回の制作で1〜数個（例4個）を得る。量・レシピ・設備・材料量をプレビューする。レシピ名/説明の変更では物理仕様と生産済みロットを変えない。別の配合は別バージョン/レシピにする。内容の正規化hashは配合（生地・整数材料量・配置・工程順・造形・技法・rulesVersion）のみから生成。ユーザー名、生成AI文、製造時刻は除外する。UIで重複を再利用可能にするが異なる名前を付ける自由は残す。

## 評価規則

**CRAFT-03 [DESIGN]** AIではなく決定論的な関数 `evaluateRecipe(normalizedRecipe, stationCapabilities, learnedTechniques, catalog)` で調理可能性と特性を計算。整数0〜100の各軸：甘み、塩味、うま味、香り、もちもち感、歯切れ、保存性、携帯性、華やかさ、満腹/回復効果。文化性は地域・技法タグ（単一優劣スコアにしない）。原価は整数の通貨単位、数量は整数。味付けや食材の極端な配合は適正範囲内に制限する。

初期の計算規則：

1. 生地・各食材の0〜100属性を量加重平均。味付けは調味料量と強度で加算する。混合に寄与しない属性は（例：形状による携帯性）形・工程の基準値から算出。
2. 仕上げ・技法・造形の属性修正ベクトルを適用し、相性タグで小さなボーナス/ペナルティ（最初は±10以内）を加える。
3. `clamp(round(value), 0, 100)`。素材間の調和は別の適性タグ・スコアとして扱い、どんな味も「失敗作」にしない。互換性のない工程は制作前に理由を表示しブロック。
4. 原価は消費した購入原価（自己採集は取得原価0、参考市場価値は別）＋消耗材＋必要な設備使用料、完成個数で分配。市場での実売価格は [経済](market-and-trade.md) が担当。
5. `rulesVersion` と生成済みロットの属性・原価snapshotを保存。バランス変更で過去の商品が勝手に変わらない。

| 工程/構造 | 初期修正の方向（例、数値は要調整） |
|---|---|
| 焼く | 香り+20、歯切れ+15、もちもち感-10、保存性+10 |
| 蒸す | もちもち感+15、香り+5、保存性-5 |
| 乾燥 | 保存性+35、携帯性+15、もちもち感-30 |
| 揚げる | 香り+20、歯切れ+20、油と対応設備が必要 |
| 笹包み | 携帯性+10、香り+5、笹を消費 |
| 花形/重ね | 華やかさ+15、携帯性-10 |

**CRAFT-04 [DESIGN]** 保存性は販売・注文・長距離配達の適性を最初に表現。初期は食べ物が自動消滅しない。鮮度システム導入時もゲーム内時刻のみ、事前警告・保存/再加工で救済、ストーリー必須品は失われない。単一の総合点を最大化するだけのクラフトにしない。

## 制作フロー

1. 作業台/公共工房で「伝統/習得レシピ」か「自由制作」。ライトユーザーは基本レシピを選択し不足材料のみ表示。自由制作は有効候補を順に選べる。
2. 材料、技法、形をプレビュー（見た目、主要特性、用途、必要数、作れる個数）。互換性エラーを原因・解決方法とともに説明。
3. 確定時に在庫/設備/習得を再検証し、材料の減少とロット付与を原子的に行う。連打・再読込・通信失敗で二重消費しない。取り消しは確定前。
4. 餅名はユーザー入力・既定のルール名・AI提案から選ぶ。名前を付けなくても制作完了。商品説明、感想は [AI](generative-ai.md) で後付け。AIの成否は制作に影響しない。
5. 食べる・保存・贈る・売る・図鑑登録を選択する。餅の回復効果には既存HP/MPの範囲とバフ上限を適用。配達物と食べ物の在庫を混同しない。

## 伝統・創作・名物・祭餅

- 伝統餅：既存17景の公式レシピ。`SCENES` の名前・外観・説明・秘密情報を尊重。原本は不変。教わったものを再現できるが、解放条件は秘境ルールに従う。
- 習得レシピ：NPC/図鑑等から学んだ固定レシピ。自由制作の起点にもなる。
- 創作餅：プレイヤーの配合、名前、発明日、発明場所、画像/造形キー、感想・販売履歴。
- 名物餅：実売・特定住民からの好評等の閾値による称号（暫定、閾値は実測調整）。強さ/文化の優劣を表す称号ではない。
- 祭餅：後工程の祭り出品候補。現フェーズで本番の祭り・エンディングを確定しない。

## 3D表現

**CRAFT-05 [DESIGN]** 既存の餅・食器・職人の実演を再利用。基本形状（メッシュ/パラメトリック）、生地色・表面粒、餡/混ぜ込み/包み、焼き目、切り口、飾りをコンポーネントで合成。レシピの量/位置と見た目を対応させ、焼き餅が蒸し餅と見分けられること。全レシピのモデルを作らず、キーによる共有メッシュ/マテリアル、遅延生成・キャッシュ・LOD・破棄。図鑑の簡易プレビューと3D展示で同じ生成ルールを使う。透明・半透明は実装と描画コスト検証後。アセット変更時に旧伝統餅を破壊しない。

## 工房での実演

配合を確定すると、主人公が工房の作業台で米を蒸し、具を用意し、臼でこねてからつく。実演では一個の餅を成形し、材料の入れ方と焼き・包みの指定に沿って仕上げ、器に盛る。配合画面の開始ボタンは一仕込みの出来高を示す。盛り付けの完了時に一仕込み分の材料を消費し、その個数を餅図鑑に登録する。途中で配合に戻れば材料を使わずにやり直せる。

焼き餅は成形台でしゃもじにのせ、焼き台でそのまま返す。焼き上がれば器へ直接運ぶ。のせ具や笹包みを仕上げるときは成形台に寄り、しゃもじを手元に置いて両手を使う。杵は臼のそばに置き、使い終えた蒸し布はその場で片口鉢に収める。

### 作業中の手と音

旅姿と同じ頬と丸い手が、杵や鉋の握りまで連続して伸びる。手を遠くへ出すほど一続きの餅が緩く細まり、戻すときには普段の丸みに戻る。柄を押した力は少し遅れて胴に伝わる。この動きを餅作りと普請で共有する。配合、調理、一時停止、作業への復帰を通して、旅先の曲と環境音が続く。
