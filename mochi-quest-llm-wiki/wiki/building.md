# 土地選択・野営地・拠点制作

プレイヤーが選んだ土地を自分で開拓し、地形・気候に合わせた和風の生活空間を作る。自由と景観保護を両立させる。

## 土地の選択

- **BUILD-01 [REQ]** ワールド上で自分が好きな土地を選び、伐採・開拓し、野営地を作る。既定の建築区画だけに限定しない。建築先では道や水路、住民の通り道、寺社や秘境の敷地を確かめる。
- **BUILD-02 [DESIGN]** 最初は `surveySite(position, footprint, intendedUse)` により設置候補を判定。地表高さと傾斜、地形種、水面・水深、風土、既存建造物・樹木・道・航路、住民経路、保護区域、他のプレイヤー設備（単一プレイヤー内の所有物）、境界ラップを確認する。地上の土地を標準とし、水中/雲上の自由建築は未決定。
- **BUILD-03 [DESIGN]** 不許可領域は寺社、文化財的ランドマーク、御朱印所、既存建物、道幅・橋・水路・港や船の動線、NPCの作業/移動・ストーリー必須地点、危険な水面、未交流の秘境。斜面の勾配に上限は設けない。京の密集地は当初保護し、住居/販売所用の許可された空地を別途用意できる。地図全体を制限区域にして自由度を失わないよう実地確認。

`PlacementVerdict {allowed, reasons[], regionId, terrainClass, requiredModules[], removableTrees[], foundationPlan}` を返す。設置不可の場合は理由と改善案を明示。緑/赤だけに依存せず、アイコンや文字でも区別する。キャンプ旗を移動させながらプレイヤーが自由に決定。配置プレビューは未確定、素材消費・樹木伐採は個別の確認操作で実行する。

| 土地 | 制作上の工夫 | 生活上の利点 |
|---|---|---|
| 平地 | 通常基礎、排水 | 初心者向け・水田や畑の配置 |
| 傾斜地 | 土地に合わせて束柱の長さを変え、水平な床を組む | 見晴らし、山の素材 |
| 川辺 | 水面より高い床・排水 | 水源・水田・水運 |
| 海岸 | 耐潮材、防風柵 | 海産物・港に近い |
| 山林 | 伐採・切り株を覆う基礎 | 木材・栗・よもぎ等 |
| 雪国 | 急勾配屋根、囲炉裏、断熱 | 乾燥/凍み・保存食 |
| 都市周辺 | 空地の利用・公共動線保護 | 商売・交流の便 |

条件は設備の効率・必要部材・見た目に反映し、適合していない設備は設置できないか効率低下を示す。建物の倒壊や火災などの苛烈なペナルティは実装しない。適合性の判定は描画側でなくゲームロジックで行う。

### 水平な基礎と木材の見積もり

敷地を回転したうえで外周・内部と各束柱の足元を測り、最高点を基準に水平面を決める。谷側には長い束柱を使い、高い脚を斜材でつなぐ。高低差18 cmまでは基本の材料で納まる。高低差のうち18 cmを超える長さに束柱の数を掛け、必要な延べ材長を出す。基礎を手動で上げると、追加高の分だけ各束柱と階段の左右の段受け材に用材を足す。竹垣には段受け材を使わない。延べ材長を2.4 mの木材の本数に換算し、最後に端数を切り上げる。柱・壁・屋根と板床に載せた櫃は、床の基礎を共用する。

場所を動かす、または回転するたびに「建てる」モードで高低差、木材の合計、うち基礎に使う本数を表示する。建て終えた時に支払い、移設では必要本数の増減を精算し、撤去時は実際に使った材料が戻る。旧セーブの建物には基礎代を遡って課さない。

## 伐採・開拓

**BUILD-04 [REQ]** 木を切って自分の土地を開拓できる。伐採可能な木にはベースワールドで再現できる安定IDを付ける。ランダムな配列位置やロード順に依存しない（生成seed・地理セル・樹種・ordinal等の組合せを候補にし、実装時に既存林を調査）。樹種・地域・道や祠からの距離・鷹の止まり木による伐採制限を外す。伐採に足場、姿勢、乗り物から降りる操作を求めない。幹・葉・影・当たり判定と樹木に付随する景物を同じ伐採記録から更新し、木材付与と伐採記録を原子的に行う。伐採済み木材の再取得は禁止。木を切る演出は既存の美術・アニメーションに合わせる。開拓は初期には木の除去＋小範囲の基礎/床による水平化を優先し、地形全体のボクセル化や無制限の掘削は非目標。

木が再生する場合も建物・畑の敷地へ勝手に生えない。土地を放棄した場合は植え直し/自然回復を任意で行う。回復前に現在の設置物との衝突を検証。

## 建築方法

**BUILD-05 [DESIGN]** 2モードを用意：①小屋・野営地を一式で選んで現地で組み上げる建築、②床・柱・壁・屋根・柵・設備の部材を組み合わせるモジュール型自由建築。自動スナップと回転・配置微調整の併用。テンプレートも部材データへ展開し、同じ保存/撤去/衝突システムを使う。材質・屋根形・色・暖簾・障子等は和風景観と既存造形に合うものから開始。

| 発展の例（固定レベルではない） | 機能 |
|---|---|
| 野営地 | 旗/寝床、焚き火、荷物置き、待機 |
| 小屋 | 収納、床・屋根、基本作業台 |
| 住居/農園 | 畑・水田・果樹、囲炉裏、庭 |
| 餅工房 | 臼・杵、蒸籠、鉄板、揚げ場、乾燥棚、加工台 |
| 屋敷 | 客間・茶室・風呂・展示、装飾、販売所 |

住居の大きさを強さや物語進行の条件にしない。小屋のままでも公共工房を使う等で同等の生活が可能。

**BUILD-06 [DESIGN]** `ModuleDef` は `id, footprint, anchors, materialCost, collision, capabilities, terrainRequirements, visualKey`。`Structure` は `id, campId, moduleId, position, yaw, variant, attachmentIds`。`Camp` は `id, name, regionId, anchor, claimedArea, structures, plots, storageId`。実際の高さはワールド座標と既存の地表判定を使用。配置/移動/撤去は対象位置とコストを再検証するトランザクション。撤去は収納・商品・作物を事前に回収/移動し、アイテム消失を防ぐ。部材の撤去で支持がなくなる構造はまとめて移設するか禁止。初期の撤去は素材を全額または明示割合返還（調整値、端数ルール固定）。設置/撤去による素材の増殖を許さない。

### 設備の機能

| 設備 | capability（例） |
|---|---|
| 臼・杵・蒸籠 | `pound`, `steam` |
| 囲炉裏・鉄板 | `grill`, `heat` |
| 揚げ場 | `fry` |
| 乾燥棚・冷却箱 | `dry`, `cool` |
| 工作台 | `build_basic`, `woodwork` |
| 収納箱 | 資源・生産ロットの保管 |
| 水田/畑/水路 | [栽培](resources-and-farming.md) の適性/灌漑 |

| 無人販売棚 | [経済](market-and-trade.md) の販売所 |

公共の餅工房で基本餅を制作できる。専門設備を買う/作る/借りる/職人と協力する複数経路を整備。

## 性能・運用

初期は本拠点1・小規模な野営地数箇所、拠点あたり約100部材以内を候補に実地測定。最大数・面積は [未確定事項](decisions.md)。大量配置を一度に描画せず、既存の地理セル/LODと共有メッシュ・マテリアル・空間インデックスを使う。常時存在するのは差分データ、近傍だけ描画/衝突を実体化。設置候補の衝突判定はNPC/船の経路も考慮し、セーブ後も同じ判定になること。

## フェーズ4で遊べる範囲

桜川・棚田・蔵町を含む地上10景で空き地を見立てる。道しるべは探し始める目安で、各景の空き地は枠をドラッグするか矢印キーで0.5 mずつ動かし、15度ずつ回して選べる。当面の上限は野営地3か所、設備は敷地の中心から24 m、共有の部材枠は合計48点。餅売り棚は3景の野営地の外にも置ける。

初期の用材は8本。「木材・収納」で近い順に並ぶ木から選ぶか、建築予定地に生えた木をその場で指定する。一本につき木材6本。棚田・蔵町では4本6文で買える。現地で鋸を引けるときは幹の前で、足場が取れないときは手元に寄った実演で伐採する。伐採済みの木と建物の位置を保存し、次に訪れたときも枝、影、衝突、敷地の草が一致する。屋根の勾配は雪国で変わる。小屋は板床・四本柱・板壁・板葺き屋根を個別部材として置く。櫃には食材と餅を預けられ、寝床では時刻を選んで休める。

## 「建てる」モード

**BUILD-08 [REQ]** 旅の画面の「建てる」、Bキー、暮らし帖から開く。新築では野営地・餅売り棚・小屋・道具櫃・板床・四本柱・板壁・屋根・竹垣を絵札で選ぶ。絵札には基本の用材と銭、見積もりには足元や高さを反映した必要数・手持ち・不足数を示す。建てられない理由は文章でも伝える。

配置枠をつかんで土地に沿って動かす。矢印キーは画面の向きに対して0.5 mずつ、回転ハンドルとQ・Eキーは15度ずつ。Shift＋上下で基礎を20 cmずつ持ち上げる。調整範囲は地面からの追加高0〜2.4 m。地形の高低差に合わせて水平を取る分は別に算出する。部材を板床に取り付けると床の高さに従う。高床の寝床・板床・櫃・売り棚には地面から登れる踊り場と踏み段を設ける。

背景をドラッグすると視点が回る。グリッドで水平面と垂直の目盛りを切り替えられる。「建てたもの」では現物または一覧で選ぶ。範囲選択の枠で囲んだ建物はまとめて移動・回転・高さ調整・撤去できる。移動中は仮置きで、地面と干渉、材料差額、支持関係を全件確認してから記録する。床を移すと壁・柱・屋根・載せた櫃もついてくる。中身のある櫃や商品・売上の残る棚を撤去しようとすると、片付けるものを案内する。

## 主人公の普請

**BUILD-07 [REQ]** 「ここに建てる」で主人公が選んだ建物の部品を1〜3点加工する。竹垣では横竹を鋸で挽き、売り棚では天板に鉋をかけて脚と横木の継ぎ手に木栓を打つ。小屋では土台・床板・柱組の3場面をつなぐ。基礎材を追加したときは束柱を寸法に挽く場面を組み込む。

主人公が手をかけ、刃を引く、あるいは木槌を振り下ろし、仕上げた部品から手を離すところまでを映す。工具の切り替えは短い和紙のカットでつなぐ。両手と刃先の見える視点を取り、足場や視界がふさがる土地では手元の作業場を映す。一時停止・再開、2倍速、取りやめ、仕上げへの早送りに対応する。完成時に場所と費用を再確認し、一度だけ会計を済ませて、完成物を選んだ編集画面に戻る。
