# 世界時計・昼夜・時間進行

固定景の美術を保ちつつ、共通のゲーム内時計で生活・商業・農業・NPCの時間を管理する。既存の船や物理挙動の時刻とは分離する。

## 時間モデル

- **TIME-01 [REQ]** 通常の地域には昼・夜を導入。`moon`（十五夜の薄野）、`dawn`（初日の出の浦）の空・月/太陽の演出は固定。追加の固定景は未確定。境界では時間帯の光と固定景の光を滑らかに補間する。地域固有の雪、秋、天気雨、雲上、海底の美術を維持する。
- **TIME-02 [DESIGN]** `worldMinute` は整数または内部固定小数で単調増加する世界時間（1日1440ゲーム分）。初期値8:00（dayIndex=0、minuteOfDay=480）。1ゲーム日=48現実分=2880実時間秒、2実秒/ゲーム分。倍率は設定/調整用で、既存の移動速度を変えない。プレイ中のみ進行する。
- **TIME-03 [DESIGN]** レンダリング/移動/船/物理に使う従来の `state.time` は別のクロック（既存単位を確認）。新時計で上書き、巻き戻し、倍率変更しない。旧京時計 `KYO_DAY_SECONDS=288` の参照先を調査し、照明・衛士・夜警・門限・山の点灯は新しい `minuteOfDay` に同調させる。船や鐘の既存周期は原則保持。鐘など時間依存演出を変更するなら個別の回帰を確認する。
- **TIME-04 [DESIGN]** 会話、メニュー、クラフト配置、明示的ポーズ、タブ非表示・終了中は世界時計停止。復帰時に実時間の差分を加算しない。昼夜固定景内も内部時計は同じ速度で進行。視覚の固定と物流/生産時刻を混同しない。
- **TIME-05 [DESIGN]** 安全な寝床/拠点/許可された宿で、朝6時、昼12時、夕方18時、夜21時への待機が可能。既にその時刻なら次の該当時刻（UIに翌日表示）。待機は明示操作のみ。乗船中、飛行/水中、危険な状態、イベント中は不可。元の移動時間を疑似高速で進めず、世界システムだけ一括更新する。NPCは待機後の予定地点へ安全に移行する。プレイヤーの位置や船の物理時刻は原則維持。

## 時間帯の初期案

| 時間 | 表現 | 行動・需要 |
|---|---|---|
| 0:00〜5:00 | 深夜 | 多くの住民が休む、夜警、夜の温泉 |
| 5:00〜7:00 | 夜明け | 朝の仕込み・出発 |
| 7:00〜11:00 | 朝 | 農業、交易、職人、商店 |
| 11:00〜16:00 | 昼 | 日中活動の中心 |
| 16:00〜19:00 | 夕暮れ | 帰宅、入浴、茶屋、点灯 |
| 19:00〜24:00 | 夜 | 休息、夜の仕事、夜景 |

商店営業時間の仮値8:00〜19:00。重要なNPCに会えない場合は次に会える時間/場所を示す。固定景は当地の生活に合うシフトを設定（常に夜の空でも全員が永遠に眠らない）。

## 時刻の伝播

`advanceWorld(minutes, reason)` は `previousMinute -> nextMinute` の区間を処理する。`dayIndex=floor(worldMinute/1440)`、`minuteOfDay=worldMinute%1440`。日次/時間帯処理は境界を飛び越えても一度ずつ処理。tick粒度は [技術](architecture.md) と各システム所有ページを参照。日長変更は今のworldMinuteを保存したまま将来の実秒変換だけ変更。既存セーブの京の位相は可能な限り保つ移行を [保存](save-and-migration.md) で扱う。

**TIME-06 [DESIGN]** ライトユーザーには「朝/昼/夕/夜」と空、必要時のみ時刻を見せる。夜間にすべての行動を封じない。特定時間の採集は代替入手手段を設ける。
