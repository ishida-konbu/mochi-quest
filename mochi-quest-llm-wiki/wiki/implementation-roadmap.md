# 実装ロードマップ・段階別の完了条件

メインストーリーを保留し、各フェーズで実際に遊べる状態を完成させていく。最初は3景の縦断ループ、次に全景と拠点・農業・生活の拡張。

## 進め方

**PLAN-01 [REQ]** システムを先行し、メインストーリーの詳細は別工程。各フェーズは合意した範囲に限定し、既存プレイとセーブの互換を確認してから次へ。実装前に [現行コード](current-repository.md) をHEADと照合する。小さく実装して実際に遊び、値を調整する。仕様に沿ったことを示す実行結果・スクリーンショット等を残す。テストだけの大規模追加・監査のための監査を行わず、ユーザーに見える機能を優先。

| Phase | 内容 | 主な依存 | 成功条件（抜粋） |
|---|---|---|---|
| 0 | 現行HEAD・テスト・保存・描画の基準確認 | なし | 旧版の起動・既存テスト、接点と影響を把握、設計差を記録 |
| 1 | 共通時計、素材在庫・採集・基本購入 | 0 | 全景の昼夜と固定景を確認、3景で素材を取得、既存保存から復元 |
| 2 | 組み合わせ餅、3D外観・図鑑、贈答/使用 | 1 | 公共工房で独自餅を作り、属性/見た目が異なり、再読込可能 |
| 3 | 基礎交易、無人販売所、収入 | 2 | 3景の異なる場所で商品を売り、売上で素材/基本設備を購入できる |
| 4 | 土地選択、伐採、野営地と建築・収納 | 1〜3 | 空地を選び、木を切り、屋根/床/設備を置く、移動・撤去、保存 |
| 5 | 栽培、NPCの日常、17景の資源/技法/経済展開 | 4 | もち米を自分で栽培・収穫、住民の時刻/好み、各景の違いが機能 |
| 6 | 生活ミッション、複数解法、秘境の認知・交流 | 2〜5 | 小さな依頼を異なる方法で解決、世界の変化/知識が保持、旧物語は維持 |
| 7 | 生成AIの3用途（任意） | 2, 5, 6 | 実際の候補モデルで命名/説明/感想を評価、無料運用と安全代替を確認 |
| 8 | 新メインストーリーの詳細設計・実装 | 1〜7の実プレイ検証、ユーザー承認 | 今回は対象外。プレイ知見から設計を開始 |

フェーズ7のテンプレート・契約はフェーズ2/5で必要分だけ用意し、実モデルの有効化は後。フェーズ5のNPC日常はフェーズ1の昼夜に必要な既存同期だけ先に行う。フェーズ3の販売所は最小の立地配置を先に実装し、フェーズ4で共通配置システムへ統合。販売所の配置を後で全く違う保存形式にしない。

## 初回縦断ループ（Phase 0〜3）

**PLAN-02 [DESIGN]** 桜川の渡し（river）、月見の棚田（terraces）、蔵町の市（market）を中心にする。昼夜機能は全景の美術へ適用（固定景を保持）し、資源・商店・技法・販売データの本格的な拡張は3景から。プレイヤーが配達/採集で資金・材料を入手、棚田や市場で米を買い、公共工房で創作餅を作り、NPCに贈る/販売所で売り、得た収入を次の制作に使う。一つのシステムずつ完成を示すと同時に、Phase 3終了時に全体を通して遊べるようにする。

### Phase 0 — 基準確認（最小限）

- `git status`, HEAD、適用される `AGENTS.md`、現行テスト・配信設定を確認。既存ブランチ・ユーザー変更を上書きしない。
- `npm test` と既存のビルド/起動手順を試す。問題が既存か新規か分ける。代表景の表示、操作、セーブ、旧引継ぎを可能な限り実地確認。
- 世界時刻・物理時刻、resource node、建築可能地/衝突、保存をどこへ接続するか短く決定。レビューは次の具体的な機能実装に必要な範囲のみ。

### Phase 1 — 昼夜と素材の取得

[時計](world-clock.md)、[素材](resources-and-farming.md)、[地域](world-regions.md)、[保存](save-and-migration.md)。時計を導入し、既存京の周期との統合・固定景・描画のブレンドを確認。素材定義、安定した採集点、数量、所持UI、購入/配達報酬を最小限実装。古い在庫・通知・小包と区別。新セーブ移行と再読込が先。天候・船・動物の物理周期を壊さない。

### Phase 2 — 餅の制作を楽しくする

[餅](mochi-crafting.md)、[UI](user-experience.md)、[AI](generative-ai.md)。既存郷土餅の基本レシピ、自由制作、配合・互換・属性計算、見た目（形・色・具・焼き目・包み）、制作トランザクション、図鑑、試食/贈答、レシピ名・説明の手動/テンプレート。最初の食材8〜12程度から始め、実際に違いを見比べる。成功後に技法・素材を増やす。見た目が変わらない数字だけの試作を最終完了としない。

### Phase 3 — 交易と無人販売所

[市場](market-and-trade.md)、[建築](building.md)、[時計](world-clock.md)。通貨・商店・販売所在庫・位置・価格・需要・回収を接続。最小の配置UIと立地判定、昼夜/地域需要、売上帳、推奨価格。異なる場所/商品で売上差を確認。遠方でもゲーム時間に従う、閉じた間は進まない。同一時間bucket二重売上なし。ここで生活ループの魅力を評価して設計を調整する。

### Phase 4 — 自分の拠点

[建築](building.md)。木のIDと保護領域を実地調査し、伐採による描画・衝突・影・素材付与を連携。自由な土地選びと不許可理由。野営地、簡単な小屋テンプレート、床/柱/壁/屋根、収納、設備、地形ごとの適合。撤去・移設・樹木の差分保存。近傍の描画・衝突の予算を測定。販売所を共通配置ルールに接続。

### Phase 5 — 農業と住民、全景展開

[資源・農業](resources-and-farming.md)、[NPC](npc-simulation.md)、[地域](world-regions.md)。水田・畑・果樹、育成・待機・収穫、設備。主要住民のスケジュール・贈答/好み・買い手、NPCの実食イベント。既存交通や日常演出を再利用。全景の資源と地域特性・郷土餅・技法・需要の差。秘境の通常流通除外。すべての景の美術と操作を現地で確認する。

### Phase 6 — 生活と物語の接点

[依頼](quest-system.md)、[祭り](festival-story-boundary.md)。小さな地域の困りごと、属性述語と複数達成経路、偶発イベント、報酬・永続的な会話/状態変化。秘境の交流許可・持出権限・知識スコープを実装。既存ストーリーの削除なし。ここで初めて物語設計者が使う機能を検証し、重要イベントの実装方法を整理する。新事件・裁判・犯人・結末は作らない。

### Phase 7 — 任意の生成AI

[生成AI](generative-ai.md)。3用途だけのテンプレートとプロバイダ契約、実モデルの日本語品質・コスト・性能・ライセンス検証。確認した無料運用条件、サーバー制限、フォールバック、キャッシュ、情報漏洩防止。公開API/課金設定の変更は承認を得る。実モデルが不適合なら標準はローカル文例のままとし、実AI採用は未完と明示。

## 各フェーズの出口と報告

[受け入れテスト](acceptance-tests.md) の該当項目、既存回帰テスト、ビルド、実ブラウザ（できない場合理由と未検証を記録）。コード・データ・Wikiの差異を更新。変更の概要、テスト結果とコマンド、セーブ移行、性能、未完/未検証、次の推奨フェーズを報告。新ストーリーの開発・公開デプロイ・費用を伴うサービス変更は別途指示が必要。

## フェーズ3・4の実装記録

桜川・棚田・蔵町の無人販売、土地の見立て、伐採、野営地、小屋、竹垣、収納、移設・撤去を実装。公共工房から出品、売上回収、米と建材の購入、伐採、建築、収納、保存・再開までをブラウザで検版した。その後、土地を決めた主人公自身が売り棚と拠点を組み上げる[主人公の建築実演](../raw/2026-11-25-construction-performance.md)をフェーズ4に加えた。伐採を全域に広げ、斜面では高低差に応じた基礎を普請する。[伐採と水平な基礎の検版](../raw/2026-11-25-open-forestry-level-foundations.md)

フェーズ4の追加要件として、絵札による新築、傾斜と高さの見積もり、直接配置と範囲編集、部品1〜3点の普請を実装した。[「建てる」モードの検版記録](../raw/2026-11-25-interactive-building.md)

世界の音を保つ普請と餅作り、探索中の伐採と再生、小屋の床に収まる寝床、夜明けまでの就寝をフェーズ4に追加した。[伐採・普請・野営の検版](../raw/2026-11-26-work-and-rest.md)

工作の丸い手、三打で深くなる伐り口、野営で体格を保つ寝返りについて、フェーズ4の検収項目を更新した。旧セーブの寝床と満腹時の実体格でも、工作・就寝を再検版した。[動作の再制作と実プレイ検版](../raw/2026-11-26-action-revision.md)

フェーズ2・4の作業姿勢を再調整した。工房、鉋・鋸・木槌、探索中の手斧を対象とし、足場と接触を保ちながら胴と肩で手を運ぶ。[改訂の経緯と検版](../raw/2026-11-26-body-led-reach.md)。鉋の往復では、手の腹を丸く保ち、手首の返しと肩が前へ出る時刻を調整した。[手首の改訂と検版](../raw/2026-11-26-rounded-wrist-work.md)。その後、通常姿勢からの体形の崩れが指摘されたため、作業中も旅のモデルを使い、道具と足場を短い手の届く位置に移した。[D-28の変更・比較画像・通常速度の映像](../raw/2026-11-26-traveller-working-pose.md)

D-29で工房は台に正対する作業姿勢に改め、普請の鉋は両手でかける。伐採では片手の横振りを保ち、着打に先行する刃と峰の順序を検査する。[作業姿勢と刃の改訂](../raw/2026-11-26-front-working-hands.md)

D-30をフェーズ2・4のローカル版に反映した。4体格で鉋の送りと材料を取るときの胴の伸び、3工房で正面の両手が餅に触れる位置を検証した。探索では片手の斧を体側から振って三打で木を倒せる。[依頼とローカル検版](../raw/2026-11-27-working-mochi.md)

D-31で3工房のかまどと臼を地面の筵へ移した。米を蒸して両手の杵でつき、調理台へ運んで仕上げる。鉋がけは足元から背が伸びる連続した輪郭に改め、作業中の瞳と完成時の笑顔を切り替えた。[ローカルでの検証と動画](../raw/2026-11-27-ground-kitchen-and-planing.md)

D-32で鉋の送りを改め、腰を足の上に残して中腹から肩と顔を前へ曲げる。3工房には地面に立って作業する一枚の調理台を設け、まな板と器を天板に直接載せる。[変更と検証](../raw/2026-11-27-planted-waist-and-kitchen-worktop.md)

D-33でフェーズ2・4の作業姿勢を改訂。餅クラフト・普請の全工程に、手の長さと胴の太さ、道具ごとの両手の役割、実際の肌と道具の接触を検収項目として加えた。3工房と小屋の実画面、4体型の手・胴の計測、606件の自動テストで確認した。[条件と検証](../raw/2026-11-27-workshop-hand-length.md)

D-34でフェーズ2・4の作業モデルを改訂し、顔の下のくぼみと胴下部の幅を検収に追加した。工房では蒸し器の蓋を開け、横の受けに置くまでを片手で行う。[同じ姿勢の修正前後と蓋の実演](../raw/2026-11-27-continuous-work-profile.md)

D-35でフェーズ2の工房の実演を改訂。蒸し器の蓋の中央を持ち、かまど・臼・調理台・焼き台の間は行き先に向いて運ぶ。[変更と検証](../raw/2026-11-27-steamer-grip-and-footsteps.md)

D-36で3工房の調理台を短くして直角に置き、蓋の中央には立てると縦になる元の木の取っ手を戻した。[旧配置との比較](../raw/2026-11-27-corner-kitchen.md)

D-37で、3工房とも正方形の筵に調理台の四脚を載せる。調理中は足場を一つに固定し、向き直りで道具と作業面を切り替える。[配置と実演の検証](../raw/2026-11-27-pivot-kitchen.md)

次はフェーズ5の栽培・住民の日常・十七景への地域展開。建築・餅クラフトの地域技法や寝具の習得順・条件は、全エリアへ展開する際に決める。
