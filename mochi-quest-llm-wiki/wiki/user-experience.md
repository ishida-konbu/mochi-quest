# プレイヤー体験・UI・アクセシビリティ

ライトユーザーに基本操作を強制せず自然に案内し、上級者には詳細な配合・建築・経済の操作を開く。既存の操作と美術を尊重する。

## 二層の操作

**UX-01 [REQ]** ゲームに不慣れでも直感的に遊べること、熟練者がやり込めること。単純な難易度スイッチではなく、基本と詳細の操作をいつでも切り替えられる構成。

| 機能 | 基本モード | 詳細モード |
|---|---|---|
| 採集 | 近づいて採る、素材の用途 | 採集点の再生、時間・地域、複数経路 |
| 餅作り | 習ったレシピ、作れるものから選択 | 自由配合、工程、技法、属性プレビュー |
| 建築 | 野営地/小屋の完成品、スナップ | 部材単位、回転、素材・地形、配置微調整 |
| 農業 | 種を植える、育てる、収穫 | 適性、区画、灌漑、作付け計画 |
| 販売 | 商品と推奨価格、売上回収 | 価格・立地・商品特性・利益比較 |
| 交流 | 会話、贈答、感想 | 個別の好み、技法、関係・履歴 |
| 探索/依頼 | 道しるべ、段階的ヒント | 地形・時間・行動・知識から推理 |

**UX-02 [DESIGN]** 初回の導入は短い任意の手引き。既存の配達を始め、少量の米と材料を手に入れ、公共工房で餅を作り、贈るか売るところまで。素材不足のときは購入/採集の候補を表示。拠点・農業・高度な市場管理は必要になってから解放/案内する。導入をスキップでき、後から手引きを開ける。長い説明を最初に読ませない。

## UIの構成（既存キーの調査後に確定）

**UX-03 [DESIGN]** 既存の `E`（調べる/話す/乗降）・`Z`（通知）・`I`（風呂敷）・`J`（帳面）・`M`（地図）・`C`（お顔カメラ）・`Esc`、移動・変身・タッチボタンを壊さない。新規の素材ポーチとシナリオ小包は風呂敷内のタブ等で区別する。キーの割り当てを既定で重複させない。複数操作候補がある場合は、近くの対象・現在の状態・選択に基づき正確なラベルを表示。モバイルは既存の画面操作で機能に到達できること。

| 画面 | 必須情報 |
|---|---|
| HUD | 通常は現在の景、時間帯、既存HP/MP、通貨（必要時）、短い操作ヒント |
| 風呂敷 | 素材/制作物/道具/小包の区別、数量、用途、収納/移動 |
| 餅工房 | レシピ、材料、設備、完成見た目、属性、所持量、確認/取消 |
| 餅図鑑 | 伝統餅/習得/創作、名前、配合、発明日/場所、販売・感想、再制作 |
| 地図帳 | 既存の名所・道しるべに資源、販売所、自分の拠点を任意レイヤーとして追加。秘境の漏洩防止 |
| 拠点配置 | プレビュー、回転、スナップ、設置可否/理由、素材費、取消/確定 |
| 販売所 | 立地評価、陳列品、推奨価格、在庫、売上回収、売れ残り、売上帳 |
| 帳面 | 依頼・観察・生活の手引き、履歴、任意追跡、旧回想と区別 |
| 設定 | AIのON/OFFと通信説明、時間倍率を設ける場合の説明、既存音/描画設定、保存/書出/読込 |

## 操作と見た目の原則

- 鳥獣戯画、絵巻、既存和風の紙・墨・朱を保つ。UIで風景を埋め尽くさない。餅の表面、粒、餡、焼き目等を観察できる。全く同じ見た目の異なるレシピを乱造しない。
- 成功を短い音/動作/表示で返す。数値だけでなく「香ばしい」「旅向き」「この町の客に好まれそう」を説明。需要予測は保証ではないと明示。
- 木に手が届く場所では通常画面に手斧の操作札を出す。伐採中にEを連打しても木材の受領は一回。土地決定、取引、消費、削除/上書きはプレビューと明確な確認。取り消し可能な範囲を示す。無駄な確認の連続は避ける。
- 文字サイズ、コントラスト、色に依存しない判定、キーボードフォーカス/タッチ対象、音なしでも分かる反応。縦横画面・低性能設定で基本操作が可能。AIがなくても日本語が自然なこと。
- ユーザー作成名は文字数/不正制御文字の検証、表示時エスケープ。名前を変更しても商品の能力や在庫・進捗を失わない。

**UX-04 [DESIGN]** 「何もしない」自由も残す。温泉、茶屋、船旅、風景、写真撮影を必ずクエストや報酬に結びつける必要はない。操作が煩雑なサバイバル要素や毎日の義務を増やさない。

## スマートフォンの建築操作

縦持ちでは現場を上、横送りの部材絵札と見積もりを下に置く。横持ちでは部材を左に並べる。指一本で配置枠を動かし、背景をなぞって見回す。二本指の平行移動で視点をずらし、指の間隔で拡大率を変える。回転と高さは画面上のボタンでも一段ずつ操作できる。範囲選択は明示的に切り替え、撤去は対象と返却額を読んで確定する。設置の理由と材料不足は色と文章の双方で伝える。[設置と費用](building.md)

## プレイテスト観点

初回5〜15分で基本ループを理解できるか（目標値）。予備知識なしに設置不可理由が理解できるか。配合を変えた結果が見た目・用途・売上に反映されるか。ゲームを閉じて翌日に戻っても何も失われないか。熟練者が複数の立地・レシピを比較する動機が生まれるか。操作自体の楽しさとワールドの美しさを数値機能の都合で損なっていないか。
