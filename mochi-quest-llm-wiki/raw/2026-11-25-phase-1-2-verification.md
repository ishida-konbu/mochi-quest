# フェーズ1・2の実装と検版記録

2026-11-25 JST。添付Wikiを基に、Mochi Quest 2の生活時計・採集と餅制作を実装した。作業対象のGitHub mainは `90cc82afb17c800e1aa657983a88721ccc3b6b94`。最初の作業フォルダは `a68abe1877e7f3515e3b0227fb0f57730c391ea5` と未コミットの変更を含んでいた。公開元との差分を照合し、公開版の動物の大きさ図鑑などを引き継いだローカルブランチ `codex/living-world-phase-1-2` に今回の差分をまとめた。

## プレイヤーができること

- 朝8時から共通時計が進む。1日は実時間48分。通常の十五景に昼夜が巡り、十五夜の薄野と初日の出の浦はそれぞれの空を保つ。京の門、灯り、夜警は生活時刻に連動する。旅籠の入口や茶屋の腰掛けのそばの13地点で、6時・12時・18時・21時まで休める。[十七景の正午と21時の比較](../../docs/living-world-review/seventeen-skies.webp)
- 桜川・棚田・蔵町に採集3地点、食材店2か所、公共工房3か所。食材は10種。素材袋はグラム、持ち銭は文で表示する。初期の支度は24文、白もち米200 g、桜の塩漬け20 g。初めて届ける三条通知のお礼でも銭と食材を得る。
- 公共工房で米100 gを一仕込みとし、具の種類・量・入れ方、味付け、形、仕上げ、技法を組み合わせて4個の餅を作る。郷土餅は花筏餅、穂の花餅、炒り豆の角餅の既存モデルを使う。創作餅は工房の見本と図鑑で同じ配合から造形する。[工房の実画面](../../docs/living-world-review/river-workshop.webp)・[郷土餅と創作餅の比較](../../docs/living-world-review/mochi-studies.webp)
- 図鑑には、餅の名前、説明、配合、制作地、制作時刻、手元の個数と感想が残る。味見では体力・モッチポイントが上限の範囲で回復する。歩いている兎や蛙のそばで贈答できる。[タッチ操作での贈答](../../docs/living-world-review/gift-mobile.webp)

## 保存

旅はversion 13、生活領域はschemaVersion 1。旧版2〜12は一度だけ支度を受け取り、生活初日の京の空を旧周期に合わせる。生活と旅は同じスナップショットに保存する。新しい保存先は `mochi-quest.two.journey.v2`。移行前のv1は元のまま保管し、前回の自動保存と、明示的な引き継ぎ・リセット前の控えを別に持つ。リセット後は旧記録の自動復帰を防ぐ。ファイルの読み込みはバージョン・参照を検証し、確認後に置き換える。大きなファイルは8 MiBまで。旧公開元の長さ制限付きリンクも利用できる。

## 検証の範囲

- 変更前の作業フォルダで `npm test` は455件成功。公開版を基にしたブランチで `npm run build` を実行し、478件すべて成功、配信用589ファイルを生成した。Node 22で旧版2〜12の移行、時計の境界、別タブ・容量不足・壊れた記録、採集再開、原価・在庫・報酬の重複、配合と外観の再現、試食・贈答を検査した。
- Chromeで新規旅から道しるべを付け、桜川の共同臼まで通常歩行し、Eで4個制作。1個を試食し、再読込後の残数3個と残りの米・桜を照合した。390 × 844のタッチエミュレーションでは現地セーブから採集の連打、食材の購入、兎への贈答、茶屋で21時まで休む操作を確認した。[休憩後の実画面](../../docs/living-world-review/rest-night.webp)
- iPhone 13相当のWebKitタッチ環境で花形の自由制作を行った。炭火設備がないときの理由、蒸し仕上げに戻した後の制作、日本語の名付けと説明、指定の桜7 gの消費を確認した。
- ブラウザでversion 12の移行元を保持し、JSON書き出し・不正ファイル拒否・確認付き読込・別タブの書込防止・確認付きリセット・未知版の保護を確認した。ローカルWorkerで `/one/` と `/two/` のHTTP 200、楽曲への512バイトのRange要求のHTTP 206を確認した。
- 桜川、Chrome、1024 × 768、軽量設定で同じ手順の測定を各1回実施した。読込から操作可能まで5.07秒→5.19秒、40フレームの画面更新間隔中央値16.7 ms→16.7 ms、JS使用ヒープ286.4 MiB→287.6 MiB。ブラウザの画面更新間隔はGPU描画時間そのものを表さない。低性能の実端末での長時間計測は未実施。
- 世界観校閲では鳥獣戯画の模本と照合した。桜川と棚田には手水鉢、炭火で焼ける蔵町には焼き網を配置し、卓に入り込んでいた穂草を移した。[東京国立博物館所蔵の模本](https://colbase.nich.go.jp/collection_items/tnm/A-1530?locale=ja)
- 造形・テクスチャ校閲では、花弁とよもぎを餅の曲面に沿わせ、餡の断面と皿への接地を修正した。焼き餅の側面に伸びていた色むら、蒸籠の側板に埋まっていた箍も直した。
- 動作・空間校閲では夜警11人の一日を60 Hzで追い、段差の踏み替えと正午の姿勢の継ぎ目を調整した。採集・購入・制作8地点と休憩13地点へ通常歩行で到達した。作業台越しの贈答、腰掛けの反対側からの休憩を修正。制作・試食・贈答は帳面の操作で確定する。[夜警の踏み替え](../../docs/living-world-review/night-watch.webp)
- プレイヤーの読解順を確かめ、花筏餅の手本と既存の台詞の半搗きを揃えた。初めての人が出発点から工房、足りない材料の仕入れ先、贈れる相手を見つけられるよう案内を調整した。
- カメラ校閲では、見本の回転に使っていない指が動くと視点が跳ぶ問題を修正した。5配合を2画面比・15方位で描き、150画面すべてで器の周囲に6ピクセル以上の余白を確認した。3工房と京の休み処で、操作後の立ち位置と視点の方位を照合した。
