# 旅の餅と並べて作業姿勢を見直す

2026-11-26 JST。ローカル作業ツリー `mochi-quest-phase-4`、HEAD `8760cfc`。比較元は[直前の手首の改訂](2026-11-26-rounded-wrist-work.md)を含む未コミット版。

## ユーザーの指摘と原因

「位置関係がおかしく、餅のポリゴンが崩れており、動きも不自然。通常状態の餅からあまりにもかけ離れたモンスターになっている。」

通常体の手の表面は左右に約1.55 m離れている。旧版の鉋は両手の握りを約0.17 mの間隔に指定し、板の奥では同じ足場で手を休めた姿勢に比べて顔が約0.49 m持ち上がった。握りの接触と手首の移動量が前回の個別検査を通っていても、全身を横から見ると顔と足の間が引き伸ばされ、頬と腕の輪郭も旅姿から大きく離れていた。

## 作業者と道具

- 主人公は旅と同じ肌・手・骨・装飾を使う。胴の傾きは足裏を支点にし、肩と顔を一緒に運ぶ。手の短い動きは元の手の骨に加える。通常体・満腹・鏡餅・満腹の鏡餅で、それぞれの平常姿勢と照合する。
- 普請では材を利き手側に固定し、短い送りと引きで片手の鉋を往復させる。台の手前には胴が入る切り欠きを作る。工房では踏み台を使い、利き手で小鉢の縁と蒸し布の寄せた端を扱う。手を休める側の頬はもとの位置に残す。
- 杵は脇から臼へ下ろす。手斧は木口に届く地面を選んで片手で横から振る。乗り物からの伐採でも足を地面に置き、終えたら旅に戻る。
- [全身の同一画角比較](../../docs/living-world-review/traveller-work-poses.webp)は左から旅姿、前回、今回。旅姿は今回と同じ足場・向きで作業姿勢を解いたもの。[通常速度の比較動画](../../docs/living-world-review/traveller-work-motion.mp4)は鉋・杵・手斧の約8秒。桜川の杵と手斧は実際の景を使った。

## ローカルでの検証

- 元のメッシュを工房・普請・伐採の72姿勢で測った。旅姿に対する体積は約99.6〜100.6%、両目の間隔と目から口までの距離は約98.0〜101.9%。鉋の送りでは短い手と刃の位置を保ち、4体格で胴が天板と交差しないことを確認した。初回の送りで約22.5 cm滑っていた通常体の足裏は、板を21.2 cm送る動作で左右それぞれ約0.5〜0.6 cmの移動に収まった。
- 市場の通常体と桜川の満腹体について杵の全工程を毎秒20回検査。手と臼・台、柄と胸・頭・空いた手の貫通は0件。斜面を含む24本の立木で手斧の刃が3打とも木口に届いた。
- 3工房×4体格で、木の下駄に載せた成形板を使って生地を押すとき、実際に描画した手の表面が狙った場所から6 cm以内に来ること、台の上面と生地・台の底と天板が4 mm以内で接することを確認した。
- 桜川の鏡餅・満腹の鏡餅で成形の3〜99%を各8姿勢検査した。下段と水引を含む飾りの頂点が、面取りした天板、支脚、蒸籠、水鉢の内部に入る例は0。天板上の点が下段に埋まる例も0。[鏡餅が桜川で成形する実画面](../../docs/living-world-review/kagami-workshop-board.webp)
- ローカルの `npm run build` で全587件が通過し、静的ファイル654件を生成した。通常画角では市場の満腹時に、移動する間だけ空いた手が柱の後ろを通ることがある。端末実機は未検証。
- ローカルWorkerの `journey-J6V5MVML.js` を実操作した。縦長のタッチ環境を模したWebKitで調理を開始し、手元の拡大、杵つき、一時停止、盛り付けの完了を確認した。Chromiumで小屋の普請を鋸から鉋・木栓打ち・完成まで進めた。別の旅で手斧を三度入れ、木材6本の加算を確認した。
