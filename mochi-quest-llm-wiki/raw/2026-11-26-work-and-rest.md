# 旅の音、手斧と普請、小屋で迎える朝

2026-11-26 JST。GitHub の main は `13fa03d`。前回のフェーズ4を収録した作業ブランチ `codex/living-world-phase-3-4` の `74e7675` から作業した。開始時点のテストは556件が通過した。

## 今回の依頼と実装

旅先の音を聴き続けながら餅を作り、建物の部品を加工できるようにする。探索中は幹の前で手斧を出し、小屋の中では寝床に入って朝を迎える。従来の絵札、配置枠、斜面の基礎見積もり、工房・敷地の確定時の会計を引き継いだ。[探索中の伐採と、小屋で夜を越す実プレイ映像（23.5秒・音声なし）](../../docs/living-world-review/work-and-rest.mp4)

- 普請では施工地点と着工回数から各工程の画角を選ぶ。斜め上、目の高さ、ローアングル、造作途中の建物を含む引き、工具を手前に置いた顔の寄りを用意した。画面比率と遮蔽物を調べ、和紙を挟むところでカットを替える。顔の寄りでは深度に応じて手前をぼかす。普請と餅作りの手は、伸ばすと前腕が細くなり、掌のふくらみと道具を握る位置を保つ。[実際の小屋普請の五画角](../../docs/living-world-review/work-and-rest-carpentry.webp)
- 立木のそばでE、または画面の「手斧で木を伐る」を押す。三打目で木材を6本受け取り、元の幹・枝葉が切り口から傾いて消える。切り株は残る。目の前の立木は樹種・地域にかかわらず、幹に手が届くかと手前に壁がないかで判定する。操作札の再入力による二重取得を防ぐ。[桜川の楓と孟宗竹での見え方](../../docs/living-world-review/work-and-rest-axe.webp)
- 自然再生の初期値はゲーム内の1,440分。建物、基礎、階段と干渉する間は木を戻さない。撤去や移設で空いた敷地を再検査する。自分のすぐそばへ幹が再生することも防ぐ。旧セーブに期限がなければ、保存された世界時刻から丸一日を与える。
- 新しい野営地も既設の寝床も、小屋の板床に置ける。野営地を開いたときの寝床を、その敷地に後から建てた小屋へ移せる。起床時刻を選ぶと、段を上り、伸び・あくび・横臥・掛け物・睡眠・起床を現地で描く。寝具の藁、端切れ、煎餅布団、ふかふかの布団は寝床ごとに保存する。鏡餅の下段と橙、腹巻も寝姿に合わせた。[一つの小屋で比べた四段階の寝具](../../docs/living-world-review/work-and-rest-bedding.webp)

## 実際のプレイで確かめたこと

- Chromium と WebKit で探索から建てるモードと餅作りへ入り、配置・配合、実演、一時停止、編集への復帰、探索へ戻るところまで操作した。桜川の曲 `inuyama-gardens.mp3` の再生位置は途切れず進み、音源の pause イベントは0回、環境音のループ3本も同じものが鳴り続けた。音源とミキサーの再生状態で確認した。
- 桜川の白樺・楓でE、西山の斜面の孟宗竹で画面の操作札を使った。三打の後、木材8本から14本、切り株、再生予定時刻を確認し、再読込でも保持した。背後から始めるとカメラが斧の見える側へ緩やかに移り、手動の見回しが優先される。
- 同じ白樺を伐った二つの旅を、再生期限の7分前から開始した。桜川の別の寝床で21時まで休み、世界時刻が2,700分になった。空地では立木が戻り、白樺の跡に野営地を建てた旅では切り株と期限2,580分が残った。どちらも休むことによる木材の増加はなかった。
- 実際の建築画面から小屋の床に野営地を置き、必要木材2本・基礎の追加0本で完成させた。床 `build-2` を支持元とする寝床が保存・再読込された。初めの野営地を既設小屋に移す場合は、床・寝具・敷地の関連を保存試験でも確認した。
- 屋外の寝床をChromium、屋根付き小屋を縦390×844のWebKitで検査した。19時に翌朝6時を選び、就寝途中の取消では元の時刻を維持。寝ている間は同じ画面で空と明かりが変わり、起床時に世界時計が1,800分になった。ふかふかの布団は再読込後も同じ寝床に残った。

- 床の回転角から算出する寝床の位置が、別のブラウザで約1.1×10⁻¹⁶ m違う例を桜川で再現した。床への取付の判定に数値許容差を設け、同じ版14のセーブがChromiumとWebKitの両方で復元できること、1 cm動かした不正な記録は両方で拒否することを確認した。
