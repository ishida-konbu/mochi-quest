# 短い腕と、足元から前へ伸びる餅の胴

2026-11-27 JST。ローカル作業ツリー `mochi-quest-phase-4`、HEAD `8760cfc` とその上にある[前回の手と鉋の変更](2026-11-26-front-working-hands.md)が今回の出発点。

## ユーザーの指定

「腕の長さはそれほど変えず、むしろ腕の付け根ごと前に寄せて、胴体の方が伸びる」「木の伐採については、両手ではなく片手で持ち、体の横から振る」「料理は、体の前に手がくることで、両手で作業できるようにしたい。奥のものを取ったり戻したりしてリーチが必要な場合は、鉋がけ同様に胴が伸びる。」

参照画の一枚目では足が元の位置に残り、通帳を差し出す手の根元まで背と腹が斜めにつながる。二枚目では鞄を持つ短い手の上へ顔が乗り出している。これを奥へ届く姿勢の基準とする。

## 実装・ローカル検版

- 普請・工房・伐採の演者は、旅の餅と同じ肌・顔・手を使う。胴の断面ごとに前へ出る量を変え、足裏と低い腹を残して背から頬までを曲げる。手と頬をつなぐ肩は左右独立して体の前へ回る。鏡餅には平たい上段に沿う付け根を設けた。
- 鉋台を手前と最も奥で比較した。通常・満腹・鏡餅・満腹の鏡餅で両手の接点は60.6 cm、口元は59.4〜61.1 cm、左右の肩の関節は56.6〜59.4 cm進んだ。奥に送って板に据え、手前に引く間の足裏、手と台木の接触、胴と天板の隙間を実際のモデルで検査した。鏡餅は幅の広い下段を板止めより後ろに据える。
- 手斧は右足を支点に腰と肩を回し、右手が脇から柄を送り出す。左手は反対側で釣り合いを取る。24本の立木で三打の刃が伐り口に届くことを照合した。
- 桜川・棚田・市の工房に花筏餅の配合を持ち込み、4体格で小豆餡を取る姿勢と手前で包む姿勢を比較した。奥へ動く距離は利き手の接点が20.5〜23.3 cm、口元が21.3〜24.3 cm、両肩が19.1〜25.2 cm。両足の目標位置は同じで、奥の材料に手を掛けたときの両手の接点のずれは最大1.5 cmだった。成形板に戻した餅は左右の掌の内側で挟む。
- 桜川の実際のカメラで、通常画角・手元拡大、横画面・縦画面を比較した。成形の188姿勢では、画面上で左右の掌が重なった面積は小さい掌の1%未満。蒸しの112姿勢では中央値0%、最大23%。この計測は掌同士の重なりが対象で、器や餅に隠れる面は含めない。
- 盛り付けでは、各工房の足場と体格に合わせた脚付き膳を元の棚に置き、器と敷き葉の高さをそろえた。3工房・4体格で両手と運んでいる餅のずれは最大2.8 cm。器に着く時点では通常体が1 mm未満、満腹の鏡餅が最大2.4 cmだった。桜川で満腹の鏡餅が餅を置く直前には、下段の飾り紐と膳の手前の縁の間に4.4 cmの隙間があった。
- [普請の鉋・桜川の工房・探索中の伐採をつないだ動画（約12秒）](../../docs/living-world-review/working-mochi.mp4)。普段の再生速度で、横からの送り、正面での両手の握り、伐り口までの一振りを見比べられる。
- `npm run build` は自動テスト592件がすべて成功し、655ファイルを生成した。ローカルの配信物 `journey-ECNSXVO3.js` を読み込み、デスクトップの Chromium で小屋の施工と三打の伐採（木材80→86本）、390×844のタッチ操作のWebKitで小屋の鉋・木栓と花筏餅の成形・完了を操作した。いずれもページ例外はなかった。
