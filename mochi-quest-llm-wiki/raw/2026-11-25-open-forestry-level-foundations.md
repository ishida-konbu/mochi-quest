# 島の木の伐採と、斜面に水平な基礎を組む普請

2026-11-25 JST。開発起点は主人公の建築実演を収めた `2c2c2c2`。確認した GitHub main は `13fa03d`。実装のローカルコミットは `0b166d7`。

> 伐採の条件はなくしてほしい。建築も斜めの場所でも立てられるようにしてほしい。斜めの場所でも基礎の増減で水平は作れる。ただし傾斜がきつければきついほど基礎の木材はより多く必要になるイメージ。

敷地の高低差が52 cmを超えると建てられなかった。今回の変更で、地形による違いを木材の見積もり、現地の束柱の高さ、斜材と踏み段に反映した。主人公が基礎から順に組み上げ、土地選び・施工・完成後に同じ部材を見ることができる。樹種、地域、道や建物に近いこと、幹に向かって徒歩で立てることによる伐採制限も見直した。

## 操作と保存の検版

- 全17景・21樹種の19,252本でIDの一意性と切り口の寸法を検査した。桃源郷の425本と月門の老桃、湖畔の柳、岩場の松、竹林、鷹が留まる木を含む。全木を伐採した旅の記録は580,235バイトで、通常のゲーム復元を通して19,252本の記録と木材115,520本を再現できた。
- 家づくりで近い順に八本ずつ手繰れる。WebKitで13.1 m先の松を選び、中止すると木材8本のまま、仕上げると14本になった。幹の前で足場を取れない場合も、お餅が両手で鋸を引く。[伐採の手元](../../docs/living-world-review/hillside-sawing.webp)
- Chromiumの土地選びで敷地の楓を指定した。中止で木材0本を維持し、伐り終えて同じ土地に戻ると6本。高低差0.50 mの野営地に本体2本・基礎1本を使い、再読込後も野営地と木材3本、楓の伐採記録が揃った。
- 横画面1000×680のChromiumで小屋、縦画面390×844のWebKitで売り棚を建てた。測量、着工、一時停止・再開、早送り、保存・再読込で金額を照合した。売り棚を緩い方へ半歩移すと基礎材1本が戻り、撤去で木材4本と6文を回収し、開始時の80本・100文に戻った。木材が2本の状態では「あと木材3本必要です」と出て、着工前に止まる。地面の櫃と板床の間でも基礎材の差額だけをやり取りする。

## 最終検証

`npm run build` で全544テストが成功し、Worker配信用の627ファイルを生成した。ローカルWorkerの `/two/` とゲーム本体 `journey-RZIFCKDX.js` は、生成したファイルとバイト単位で一致した。配信用の通常画面から、小屋・売り棚の新築と保存再開、売り棚の撤去、敷地の楓の伐採から野営地を建てる一連の操作を確認した。設計Wiki全20ページの相対リンク、出典、ページIDの重複、および `git diff --check` を確認した。実装と検証記録はローカルの開発ブランチに保存した。
