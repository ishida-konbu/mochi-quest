# 鉋を送り、短い手を返して引く

2026-11-26 JST。ローカル作業ツリー `mochi-quest-phase-4`。比較元はコミット `8760cfc` に[前回の胴と肩の調整](2026-11-26-body-led-reach.md)を加えた作業中の版。

## 依頼

ユーザーは「鉋を板の奥へ押すときなど、まだ手先が尖って見えます」「短い手の丸みを保ったまま、短い手のスナップと、胴と肩が前へ出る動きをもう少し詰めてください」と指定した。前回添付の参考絵では、手が物に触れていても先が丸く、胴が足元から斜めに伸びる。今回もローカル反映の指定。

## 動き

- 鉋を手前で取り、刃を浮かせて板の奥へ送る。鉋の前後移動が止まってから約0.1秒で肩が追いつく。鉋台が水平になったところで、前後の手を当てたまま手首の向きを返し、手前へ削る。押さえ手の返しは引き手より小さい。[同じ視点・同じ工程で比較](../../docs/living-world-review/working-grip-comparison.webp)
- 握りに当たる丸い面、手首、頬の付け根をひと続きの餅として変形させる。鉋や鉢では手の腹に力が乗る。片手の木槌・杵・手斧では、構える時と打点で手首の向きが変わる。木槌の反対の手は材を押さえる。[通常速度と手元のスロー映像](../../docs/living-world-review/working-grip-motion.mp4)

## ローカル検版

- 通常体と鏡餅、それぞれの満腹時を含む4体格で実モデルの頂点を測定した。鉋が傾いたときも手の腹に縦横の幅が残り、送りと引きで手首が逆向きに動くこと、握りの位置、奥で前へ出る顔と肩、足裏の位置を確認した。
- 通常体の引き手では、同じ握り・同じ姿勢で手首の返しだけを切った状態と比べ、手首の中央が送り側へ約6.9 cm、引き側へ約6.8 cm動いた。傾いた鉋台の上面から16 mm以内にある手の幅は、送りで約12〜13 cm、荷重して引くと約16〜17 cmだった。
- ローカルの `npm run build` を実行し、全582件のテストが通過、静的ファイル654件を生成した。比較用の映像は12.45秒で、前回の未コミット版と同じ画角で送り・引き・打点を照合した。
- ローカルWorkerで同じ `journey-CNXGYOSG.js` を読み込んだ。縦型のタッチ環境を模したWebKitで調理開始から杵つきまで進め、手元拡大・一時停止・仕上げを確認した。Chromiumでは小屋で鋸から鉋、木栓打ちまで進み、鉋の一時停止・再開と普請の完了を確認した。別の旅で伐採後の木材6本加算も確認した。端末実機は未検証。
