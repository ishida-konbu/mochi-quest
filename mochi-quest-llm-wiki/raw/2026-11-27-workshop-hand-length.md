# 餅クラフト・建てるの手と胴

2026年11月27日、ローカル作業ツリー `mochi-quest-phase-4`（HEAD `8760cfc`）での改訂。

## ユーザーの条件

> 餅の手の長さは変えない。
>
> 手の付け根の位置は動いて良い。
>
> 胴体は伸縮してよい。ただし、温泉に入った時と同様に、なるべく体の太さは一定に。
>
> ポリゴン崩れや、オブジェクトとの重なりがあってはならない。
>
> ノコギリ、カンナは両手で。ハンマーは片手で木材を押さえ、もう片手で叩く。

対象は「餅クラフト」「建てる」の全工程。前回の参考画から個別に決めていた鉋の腰・顎の形は検収基準から外した。今回は工程ごとの実際の手の長さ、胴の太さ、道具や設備との位置関係を調べる。以前の工房配置と地面からの作業は[前回の記録](2026-11-27-planted-waist-and-kitchen-worktop.md)に記載した。

## 実装

- 温泉のモデルが足元と手の間で伸びる量を、作業用の胴にも使う。立ち姿からの高さと奥行きは左右の手の目標から求める。手は付け根から先まで一体で動き、左右それぞれの手のひらを道具に向けて握る。
- 肩が移動すると見える脇の肌を張り直した。元の手の跡にあった凹凸の境界を保ったまま細かく三角形を張り、曲げたときに隣の面と交差する長い対角線を取り除いた。絵で表情を描く口元も、以前の彫り込みを平らにした部分に折り返しが残っていたため、作業モデルの内側の頂点を均した。
- 鋸は両手が柄に並ぶ向きに構える。鉋は左右の縁を握って36 cmの範囲を往復する。木槌は利き手で振り、反対の手を別の位置に置いて部材を押さえる。立ち位置、柄の握り幅、材を押さえる場所を四つの体格に合わせた。
- 蔵町では調理台に立つ間、のれんの支柱の間から顔と両手を望む。手の幅と顔の幅も含めて支柱との見通しを確かめる。
- 地面のかまどでは、米鉢をいったん置いてから蓋の桟を両手で握る。蒸し布の両端を握り、蒸籠と臼の縁を越してから下ろす。杵は持ち上げるところから米に当てるところまで両手で持つ。
- 調理場を歩く餅と町のウサギが同じ場所を通る問題も修正した。村人の周回路は、三つの工房の入口から筵へ向かう範囲と杵置きをよける。
- 調理台では、具を取る手の反対側でまな板を押さえる。片方の手が葉の端を押さえている間にもう片方で笹を折る。団子モードでは作業に入ると転がる姿勢をほどき、手と足を出して構える。

## 確認した動き

- 小屋の施工と桜川・棚田・蔵町の郷土餅を、通常餅と鏡餅の空腹時・満腹時に毎秒20回、計16,559姿勢で計測した。手の長さと幅の変化は浮動小数点の計算誤差内。胴の高さ7か所で静止時からの直径の変化を測ると、左右は最大2.01%、前後は通常餅で最大6.47%、鏡餅で最大11.26%だった。
- 柄・材・木槌との接触は動いている手のメッシュから調べた。鋸・鉋は二つの接点、木槌は打つ手と押さえる手を毎秒30回確認。調理では具なし、郷土餅に加え、具を3種類使う包み焼きも通し、手と手の交差、板や蒸籠・臼・米桶を通り抜ける箇所を調べた。
- 作業で露出する両脇と口元のポリゴンの向きを調べた。施工、3地域の配合、包み焼きの各工程で採った姿勢では、胴の離れた面同士の交差は0件だった。
- 通常餅・鏡餅・団子・羽二重・草餅・きなこ餅で、空腹時と満腹時に描画した左右の手の三角形を照合した。郷土餅3種と具3種類の笹包み焼きを毎秒12回採った範囲で、手同士の表面の交差は0件だった。
- [ローカル実機映像（約26秒）](../../docs/living-world-review/workshop-hands-and-tools.mp4)に小屋の鋸・鉋・木槌、蒸し布、餅つき、成形、炭火、笹包みと盛り付けを収録した。
- ローカル配信版を Chrome のデスクトップ画面と WebKit のタッチ画面（390×844）で操作した。小屋は鉋で一時停止・再開し、木栓を打って保存。木材は76から66になった。桜川と蔵町の料理は、一時停止・再開後に一仕込みが保存され、白もち米が200 gから100 gになった。セーブ形式の変更はない。
- 最終ソースで `npm test` は606件成功。`npm run build` は606件成功後に655ファイルを生成し、ローカル配信のゲーム本体とビルド出力は同一だった。
