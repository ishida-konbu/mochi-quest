# 『十七景もち寄り帖』実装計画

三条通知の配達人であるお餅が、十二個あるはずの桜餅を数え直すところから始める。依頼を届けること、道具の受領を記録すること、祭への参加を決めることをプレイヤーが少しずつ区別できる構成にする。

| 巻 | 実地の調査 | プレイヤーが説明すること |
| --- | --- | --- |
| 一・桜餅 | 渡しで店主と舟の運び手の話を聞き、籠と大餅の裏を調べる | 十一個に見えても十二個分届いた理由 |
| 二・蒸し箱 | 米・火・段数・桟を変えた結果と楓峡の試作を比べる | 蒸気が止まった箇所と直し方 |
| 三・婚礼の餅 | 異なる餡、布の繕い跡、工程ごとの目撃をつなぐ | 名人と弟子それぞれの仕事 |
| 四・二つの港 | 桟橋、積替え、船倉で見えた範囲を分ける | 同じ外箱を使った二便と、別の箱の落荷 |
| 五・消えた職人 | 足取りと預け札をたどり、桃源郷の本人と竜宮の拾い主に会う | 休む意思と道具の行方 |
| 六・第一の裁判 | 十五組の購入内訳、貸出先、戻す予定を調べ、白洲へ | お澄への嫌疑と京の茶屋に残る一組 |
| 七・第二の裁判 | 以前の受領書、後から届いた問い合わせ、搬入変更の実行、提出書類を照合する | 八重が何を知り、誰の意思をどう伝えたか |
| 終幕 | 仕事と報酬を相談し、二つの秘境へ招待を届け、京で祭を開く | 土地ごとに出す量や役割を決めた結果 |

## 遊びの組み立て

- プレイヤーが持ち帰るものを「次に確かめられる問い」にする。章の中では独立した聞き込みを好きな順で進められる。誰かが答えを知った経緯が必要な質問は、対応する観察や証言を得てから開く。『Outer Wilds』の脚本担当者が説明した、疑問を残す発見と探索先を知らせる記録を参考にする。[GDC講演・Sparking Curiosity-Driven Exploration Through Narrative](https://www.gdcvault.com/play/1027008)
- 『Heaven’s Vault』で開発者が示した、別の順で証拠を発見しても会話と推理が続く設計を参考にする。港の調査は敦賀・堺のどちらからでも始められる。第一の裁判では茶屋を先に調べたら京の一組だけ、地方の控えを先に見たら十四組だけが地図に載る。[inkle・Heaven’s Vault](https://www.inklestudios.com/heavensvault/) ／ [Jon Ingold・Creating a Dynamic Detective Story](https://www.youtube.com/watch?v=o02uJ-ktCuk)
- Eで現地の会話・観察に入り、Zで従来の通知を届ける。旅の途中からでも始められ、配達人数や移動手段の解放を参加条件にしない。現地へ戻るための正確な道しるべを帳面から選べる。
- 観察・証言・推理の記録を分ける。二度の裁判では個々の争点について、証拠を選んでからその意味を説明する。誤答には見直す箇所を返し、再審理できるようにする。
- 各地の作業台に郷土餅と道具を置き、人物の顔・姿勢・職道具で話者を見分ける。手元に大きく出した立体で、裏面や継ぎ目も確認できるようにする。
- 墨線の太細、動物の身体に沿った所作、紙の余白を主役にする。色は土地・素材の見分けと押印に使う。指定された山崎董詮の模本と東博の断簡を参照する。[ColBase・鳥獣戯画（模本）](https://colbase.nich.go.jp/collection_items/tnm/A-1530?locale=ja) ／ [e国宝・鳥獣戯画断簡](https://emuseum.nich.go.jp/detail?content_base_id=101318&langId=ja)
- 章、証拠、弁論の途中、祭の開催を既存の旅と一緒に保存する。旧版の旅には桜川で最初の問いを開く。

## 現地の所作と回想

調査五十一件、推理十九問、各巻の結び八件、土地の餅十七種、五十九人の通常の仕事、祭の客六人、桃林で休む弥平をそれぞれひとつの場面とする。各場面に役者、品、手を掛ける部位、相手、所作の順序と字幕を持たせる。記録済みの場面は帳面から呼び出し、当時の場所と役者を再現する。解決前の問いと結びは初見の記録に従って開く。

餅と器を別々の部材として作る。笹の葉と海苔、昆布の帯は手の動きに合わせて開閉し、割る餅は切り口の餡と粒の見え方も変える。机は職人が台に置く物、支える重さ、仕事中に取る姿勢から設計する。現地の仕事台と実演で同じ造形と天板高を使う。
